# 分诊标签

技能用五个固定角色说话。本文件把角色映射到本仓库跟踪器里实际使用的标签字符串。本地 markdown 模式下，标签就是 issue 文件顶部 `Status:` 行的值。

| mattpocock/skills 里的角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要先评估 |
| `needs-info` | `needs-info` | 等报告者补信息 |
| `ready-for-agent` | `ready-for-agent` | 已写清，可交给 agent 无人值守做 |
| `ready-for-human` | `ready-for-human` | 必须人来做 |
| `wontfix` | `wontfix` | 不做 |

技能提到某个角色（例如「打上 AFK-ready 标签」）时，用上表对应的字符串。要换词只改第三列，别改角色名。
